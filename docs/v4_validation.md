# v4 评分验证 / v4 validation

生成 2026-10-17T10:45:30。训练 ≤ 2025-12-31，**2026 为留出测试集**（只汇报，不参与选参）。

**成本优势(%)的含义**：花同样多的钱，按倍数表买到的股数比“把这笔钱平均摊到每个交易日”多出多少 %（等价于平均持仓成本低多少）。是整个区间的累计数，不是年化。

**约束**：各年加仓天数（1.5x/2x）平均约 1/6～1/5（非硬性，大熊市年可更高，大熊市年可达 50-80%）；估值权重 ≥ 回撤权重；对比时各变体统一为训练期约 18% 的天数加仓。倍数档位固定 1.0 / 1.5 / 2.0。
